# Omni Quantum Dual Helix Core (OQ-DHC) — Legacy Mirror

This directory is a packaged compatibility mirror of the main project and is intended for reference, bundling, or archival use.

The canonical working repository is the parent project root. That root contains the active source, documentation, SDK, hardware, and test organization.

## Mirror structure

```text
oq_repo/
├── src/
├── tests/
├── sdk/
├── docs/
├── kicad/
├── fpga/
├── README.md
├── Makefile
├── DOKUMENTATION_UND_GENESE.txt
└── artifacts_out/
```

This mirror intentionally reflects the same general project composition as the root repository but should not be treated as the primary source of truth when working on the active development tree.
